# MTProxy Checker

Этот проект проверяет список MTProto прокси из публичного источника, фильтрует рабочие с помощью MTProto handshake и сохраняет их в JSON для отображения в веб-интерфейсе.

## Установка

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

## Запуск

1. Запустите скрипт для проверки прокси:

   ```bash
   python main.py
   ```

2. Откройте `index.html` в браузере для просмотра результатов.

## Тестирование

Запустите unit-тесты:

```bash
pytest tests/
```

## Безопасность

В текущей версии SSL отключен для fetch из-за требований источника. В продакшене рекомендуется включить SSL.

## Логирование

Логи записываются в консоль с уровнем INFO. Включают причины отказов прокси.
